# Monteiro Monitoramento Veicular

> **Segurança em movimento** — Seu veículo sempre no seu radar.

Site institucional (landing page) da **Monteiro Monitoramento Veicular**, empresa de rastreamento e monitoramento de veículos e frotas com sede na região de Sorocaba/SP (DDD 15).

---

## Sobre o projeto

Página estática em HTML único que apresenta os serviços, planos e diferenciais da Monteiro. O objetivo é converter visitantes em clientes por meio de uma apresentação clara dos produtos, depoimentos e chamadas para contato via WhatsApp.

**Tagline:** *Tecnologia que acompanha o que mais importa.*

## Diferenciais

- **Proteção total** — monitoramento completo do veículo
- **Acesso fácil** — aplicativo e plataforma web
- **Eficiência para frota** — gestão de múltiplos veículos e motoristas

## Funcionalidades / Benefícios

| Funcionalidade | Descrição |
|---|---|
| 🛰️ Rastreamento em tempo real | Localização do veículo no mapa ao vivo |
| 🔔 Alertas inteligentes | Notificações de eventos e comportamentos |
| 📱 Aplicativo Android e iOS | Acompanhe pelo celular |
| 🚫 Bloqueio remoto | Bloqueie o veículo a distância |
| 🚛 Gestão de frotas | Controle de múltiplos veículos |
| 🎥 Videotelemetria com IA | Câmeras inteligentes que identificam fadiga, uso de celular e direção perigosa |

## Como funciona (passo a passo)

1. **Entre em contato** — fale pelo WhatsApp
2. **Escolha o plano** — selecione a proteção ideal
3. **Faça a instalação** — instalação do rastreador
4. **Acompanhe tudo** — monitore pelo app ou web

## Stack técnica

- **HTML5** + **CSS3** + **JavaScript** (tudo em um único arquivo, sem dependências externas de build)
- Layout responsivo (mobile-first)
- Monitoramento de performance com **New Relic Browser**
- Idioma: Português (pt-BR)

## Como executar

Não há build ou dependências. Basta abrir o arquivo no navegador:

```bash
# Abrir diretamente
open monteiro-site.html

# Ou servir localmente
python3 -m http.server 8000
# Acesse http://localhost:8000/monteiro-site.html
```
